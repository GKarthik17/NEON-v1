# NEON v1 – Feature Freeze

## Included in v1
- FSM-based behavior control
- Command-based interface
- Task Manager (active & passive)
- Time-based supervision
- Avoidance detection
- Burnout detection (earned fatigue)
- Protected RECOVERY state
- Manual recovery override
- Memory persistence (JSON)
- Non-blocking main loop

## Explicitly excluded from v1
- Learning / self-modification
- Natural language understanding
- MCU integration
- Networking / internet access
- Autonomous goal creation
- Emotional manipulation
- Continuous debate mode

## Status
NEON v1 is feature-complete and frozen.
All future changes must target v2.
